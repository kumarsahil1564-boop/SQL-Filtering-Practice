# SQL Filtering Practice

## 📌 Project Overview

This project demonstrates common SQL filtering techniques using a sample employee dataset.

The project focuses on practicing:

- WHERE
- IN
- BETWEEN
- LIKE
- AND conditions

## 🎯 Objective

The objective of this project is to understand how SQL filters records based on specific conditions.

## 🛠️ Tools Used

- MySQL
- SQL
- GitHub

## 📊 Dataset

The project uses a sample `employees` table containing:

- Employee ID
- Employee Name
- Department
- Salary
- City

## 🔍 SQL Concepts Practiced

### WHERE
Used to filter records based on a specific condition.

### IN
Used to match values from a given list.

### BETWEEN
Used to filter values within a specific range.

### LIKE
Used for pattern matching in text values.

## 📋 Queries

A total of **12 SQL filtering queries** are included in:

`sql_filtering_practice.sql`

The queries demonstrate different filtering conditions and combinations.

- `README.md` — Project documentation
- `sql_filtering_practice.sql` — Database, table, sample data and 12 filtering queries
